# Getting Started
{: .no_toc }

Everything you need to know to start using FORGE Framework with Claude Code subagents.
{: .fs-6 .fw-300 }

Start by picking an implementation: [Choosing an Implementation](/forge/implementations/) covers the canonical Claude Code skill, the forge-kit enforcement layer, the standalone CLI, and the MCP server. The pages in this section walk through the standalone forge-framework CLI, which configures specialized Claude Code subagents during installation, giving you instant access to AI experts in architecture, development, testing, DevOps, code review, and project analysis. These guides will help you understand the core concepts and get building quickly.
